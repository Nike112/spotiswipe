The problem

            

              Listeners need a quick way to express their preferences and
              discover unfamiliar music without ending up with a repetitive
              playlist. Spotiswipe turns explicit feedback into ranked discovery
              and then builds a mix under practical constraints.
            

            
The selected service: Amazon Personalize

            

              Amazon Personalize uses interaction datasets and optional
              item/user metadata to train models and return personalized
              recommendations. This project simulates dataset import,
              solution-version training, event recording, ranking and filtering
              locally.
            

            

              Our item-to-item cosine co-occurrence model learns from positive
              listener histories. Live genre feedback and mood matching
              supplement the trained model. A left swipe is our
              application-level negative signal, not a claim about AWS’s event
              semantics.
            

            
The additional enhancement

            

              The playlist optimizer greedily balances relevance, unfamiliar
              genres and genre coverage while enforcing a duration ceiling and
              an artist cap. It reports calculated variety and relevance beside
              a relevance-only baseline. It does not guarantee a globally
              optimal playlist.

What this simulation does not provide

            

              No real AWS resources, distributed serving, automatic retraining
              schedule, cloud user accounts or Spotify-trained model. All
              fixture tracks, metadata and listener histories are synthetic.
              Browser storage is local and can be cleared; this is not a shared
              cloud database. The generated demo sound is a short illustration,
              not the named track.
            

            

              The original Spotify app is preserved separately and does not feed
              this model. Spotify content must not be ingested into
              machine-learning models.
