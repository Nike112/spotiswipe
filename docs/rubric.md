# Evaluation rubric mapping — 10 marks

| Criterion                       | Marks | Implemented evidence                                                                                     | Demonstration                                                                   |
| ------------------------------- | ----: | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Understanding of AWS service    |     2 | Service workflow, concept mapping, source links and explicit simulator limitations                       | Explain dataset → solution version → recommendation serving → event feedback    |
| Core functionality / simulation |     3 | Import, validate, train, personalized ranking, event collection and filters                              | Compare seeded profiles, record swipes, train another version, inspect requests |
| Enhancement / tweak             |     2 | Duration- and artist-constrained discovery playlist optimizer                                            | Vary discovery and compare computed diversity and relevance with plain ranking  |
| UI/UX and working website       |     1 | Responsive views, accessible controls, score explanations, keyboard/pointer swipes and local persistence | Use on desktop/mobile; reload after swiping                                     |
| Deployment and GitHub           |     1 | Organized repository, tests, static deployment instructions                                              | Pending faculty approval and actual publishing; record real URLs afterward      |
| Demonstration and explanation   |     1 | In-app project guide, architecture document, demo script and viva answers                                | Walk through the real data flow and explain tradeoffs                           |

Implementation evidence does not guarantee a mark. Faculty determines whether the selected scope sufficiently simulates the service. Do not present the original Spotify feed as Amazon Personalize output or synthetic evaluation as real-world validation.
